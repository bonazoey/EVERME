# 검증 기록

## 2026-11-28: 비활성 20쌍 요약·정리 및 정보이용자 이력 RAG

- 활성 최근 20쌍은 유지한다. 21쌍에서는 비활성 1쌍·요약 0개, 40쌍에서 첫 20쌍을 요약한다. 요약된 비활성 context만 같은 트랜잭션에서 삭제하고 영구 session_messages는 유지한다.
- 재조회 시 삭제 구간이 재삽입되지 않으며, 여섯 번째 요약 실패 시 기존 5개와 미처리 원문이 유지된다. JDBC 재생성 후 활성 20쌍을 복구한다.
- searchViewerHistory는 현재 owner/viewer/session으로 제한한다. 과거 NULL 임베딩은 검색 시 보완한다. 정보이용자 이력은 소유자 검색·프로필·장기기억에서 제외한다.
- VIEWER_RAG 출처는 우측 정보이용자 대화 정보에 표시한다. 다른 이용자의 대화방 접근 및 정보이용자 출처를 소유자 사실로 잘못 분류한 인용을 거부한다.
- 모의 모델·테스트 DB로 전체 Gradle 테스트 82개 통과. 마지막 보완 후 관련 테스트 22개 재통과. 실제 OpenAI 호출은 하지 않았다.
- 최신 정적 화면과 모의 API로 PC/390px/320px 레이아웃·출처 6종·두 그룹 표시·HTML 이스케이프를 검증했다. DBML 파싱도 통과했다.

- 답변에 짧은 reason과 provenance 스냅샷을 저장한다. 페이지 재조회와 이전 답변 선택 후에도 당시 원문·요약·요소 수치·출처 ID를 확인할 수 있다. 이전 형식 답변은 상세 기록 없음으로 표시한다.
- 관련 테스트 26개 통과: 출처 검증 4개, 선택한 DB 통합 테스트 9개, OpenAI 클라이언트 회귀 13개. 실제 모델 호출은 하지 않았다.
- 브라우저 모의 API로 출처 5종·인용 카드·판단 근거·이전 답변 선택·원문 HTML 이스케이프와 PC/390px/320px 가로 넘침 없음을 검증했다.

## 2026-11-28: 14개 테이블·JDBC ChatMemory 전환

- 로컬 `everme-clone-lab` 컨테이너의 `everme_lab.clone_lab`을 교체 migration으로 삭제·재생성했다. 14개 테이블, session_messages 중복 식별 컬럼 제거, context embedding 제거, sessions.memory_key 생성 컬럼과 FK를 확인했다. legacy 스키마는 없고 실제 실험 DB는 빈 상태다.

- 별도 `everme_lab_test` DB와 모의 모델로 전체 Gradle 테스트 **73개 통과, 실패·건너뜀 0개**. 일반 애플리케이션·기존 엔드포인트·Lab 격리·AI 전송·점수 검증을 포함한다.
- 통합 테스트 38개에는 모의 1000쌍 생성·분석·순차 저장, 동시 생성/분석·20쌍 미저장 상한, 중단·실패·복구, 원문 1000쌍 유지·900쌍 장기 보존, 범위 격리, 네 답변 경로가 포함된다.

- 임베딩 실패 시 원문·NULL 벡터 보존, 저장 전 임베딩 재시도, 실패 시 프로필 미반영을 확인했다. 장기 복사 실패 시 프로필·상태·기억의 원자적 롤백도 통과했다.

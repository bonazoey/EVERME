# 140개 요소 명세

0~100 독립 점수. 50은 중간, NULL은 근거 부족이다. 아래 사례는 판단 지침이며 문장 하나만으로 극단 점수를 확정하는 규칙이 아니다.

## 정서·자극 반응

- 기준: 0=매우 낮음·거의 없음 / 25=낮음 / 50=중간 / 75=높음 / 100=매우 높음
- 경계: 불확실한 상황에서의 불안에 직접 해당하는 근거만 사용한다. 선택 과정·실행 습관·표현 방식는 이 점수로 대신 측정하지 않는다.
- 근거 예: 결과를 모르는 일이 있으면 다른 일을 못 할 만큼 계속 걱정해요.
- 오판 예: 주제에 불확실한 상황에서의 불안이 등장했다는 이유만으로 사용자 특성을 단정하지 않는다.

### expression.structure — 목록·구조화 사용

- 기준: 0=매우 낮음·거의 없음 / 25=낮음 / 50=중간 / 75=높음 / 100=매우 높음
- 경계: 목록·구조화 사용에 직접 해당하는 근거만 사용한다. AI 답변의 말투·내용의 가치관·실제 행동는 이 점수로 대신 측정하지 않는다.
- 근거 예: 사용자 원문: 1. 예산 확인 2. 일정 결정 3. 예약 순서로 진행합시다.
